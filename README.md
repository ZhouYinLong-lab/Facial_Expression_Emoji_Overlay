# 表情 Emoji 图片编辑器

一个本地网页小工具：上传图片后，在浏览器中识别人脸和近似表情，并自动覆盖可选风格的透明 SVG emoji，最后导出清晰 PNG 图片。

![应用展示](assets/demo.png)

## 功能

- 导入本地图片进行编辑
- 使用 MediaPipe Face Landmarker 检测图片中的全部人脸
- 根据面部 blendshape 近似识别开心、悲伤、生气、惊讶、中性五类表情
- 自动将对应 emoji 覆盖到每张脸上
- 支持手绘贴纸、像素风、纯色扁平三种风格
- 切换风格时保留已有贴图的位置、大小和旋转
- 在图片上右键添加随机手动贴图
- 左键拖动 emoji 可移动位置
- 拖拽 emoji 的选中边框可等比例放大或缩小
- 新增 emoji 会沿用最近一次调整后的尺寸
- 支持滚轮缩放图片视图、拖拽平移图片
- 导出 PNG 时按原始图片尺寸重新绘制，保持画质清晰

## 使用方法

项目不需要安装依赖或启动后端服务，但由于浏览器的 ES Module 和本地文件安全限制，建议通过本地静态服务打开。

1. 点击“导入图片”选择本地图片。
2. 选择喜欢的 emoji 风格。
3. 点击“识别并贴图”，自动处理图片中的全部人脸。
4. 左键拖动 emoji 调整位置，拖动边框调整大小。
5. 也可以在图片上右键添加随机手动贴图。
6. 使用鼠标滚轮缩放图片视图，拖拽空白图片区域平移视图。
7. 点击“导出 PNG”保存编辑后的图片。

如果浏览器对本地文件访问限制较严格，也可以在项目目录运行本地静态服务：

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:5173/
```

## 技术说明

项目使用原生 HTML、CSS 和 JavaScript 实现。MediaPipe 运行时和 Face Landmarker 模型通过 CDN 加载，项目无需构建工具或后端服务。图片和识别结果只在浏览器本地处理，不会上传到服务器。

编辑数据保存在原始图片坐标系中，页面缩放和平移只影响预览视图；导出时会在离屏 canvas 中按原图尺寸重新绘制图片和 SVG emoji。

表情识别是基于面部 blendshape 的近似分类，适合生成趣味贴纸，不代表医学或心理层面的情绪判断。首次识别需要网络加载 MediaPipe 运行时和模型；如果模型加载失败，仍可使用右键手动贴图和导出功能。
